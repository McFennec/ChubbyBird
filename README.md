# Chubby Bird

**Chubby Bird** est un jeu inspiré du célèbre *Flappy Bird*, développé sous Unity. 
- Le joueur contrôle un oiseau qui doit éviter les obstacles en volant entre des tuyaux. 
- Le jeu comprend un système de score, un highscore persistant et un écran de menu.

## Fonctionnalités

- Vol fluide et réactif avec un simple clic ou appui sur la barre espace
- Génération procédurale des obstacles
- Gestion du score et du highscore sauvegardé
- Interface utilisateur intuitive
- Menu d’accueil avec bouton Play/Quit
- Sons d'effets (SFX) et musique de fond avec gestion dédiée

## Technologies utilisées

- [Unity](https://unity.com/)
- C#
